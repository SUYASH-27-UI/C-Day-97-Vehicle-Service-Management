# C Day 97 - Vehicle Service Management System

## Description
A menu-driven Vehicle Service Management System developed using C. It manages vehicle service records and stores information in a text file.

## Features
- Add vehicle service records
- Display all records
- Search vehicles by ID
- Update service costs
- Delete service records
- Save information permanently

## Files
- `service.c` - Main C program
- `vehicles.txt` - Vehicle service records

## How to Compile
`gcc service.c -o service`

## How to Run
Windows: `service.exe`

Linux: `./service`

Keep `vehicles.txt` in the program's working directory.

## Concepts Used
- Structures
- Arrays
- Functions
- File Handling
- Searching
- Updating and Deleting Records
